# CPUGauage

CPUGauge is a demo applicationt that display CPU and disk usage of a machine on a phyiscal gaugge using YoctoServo.
You can read our full article on this application on our blog: https://www.yoctopuce.com/EN/article/physical-vu-meter-for-monitoring-a-computer
## Installation

this simple application require two python package:
- ``yoctopuce`` to acccess Yoctopuce devices
- ``psutil`` to get the CPU usage

You can install both package using pip

````
pip install yoctopuce
pip install psutils
````
